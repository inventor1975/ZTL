# Обычный базис, ЗАМОРОЖЕН v1 — 2026-08-31

Заморожено ДО продолжения переписи. Если вычислитель менять по ходу осмотра
следующих случаев, остаток станет адаптивным — та же беда, что адаптивная
остановка.

## Точный алгоритм

    для каждого значения неизвестного из его КОНЕЧНОЙ области:
        посчитать ПОЛНОЕ последствие
    если все последствия совпали -> проверка не нужна

Три строки. Никакого ZTL, никакого примитива `settles`, никакой подстройки
под случай.

## Реализация

| поле | значение |
|---|---|
| файл | `inventory/tau_airline/classify_baggage.py` |
| функция | `generic_baseline_eliminates(cabin, bags)` |
| sha256 файла | `9f1ff6e433509d5340c4964d83ef6de93f12a16782dd0d361ddd6155f3092d99` |
| последствие | доплата в долларах: `50 * max(0, мест - норма(уровень, класс))` |
| сравниваемые поля | ПОЛНОЕ последствие (одно поле: доплата). Разрешение по багажу от уровня не зависит |
| конечная область | уровень членства: regular, silver, gold — из `wiki_airline.md` строка 36 |
| допустимое знание | таблица норм, класс, число мест |
| неизвестные значения | перебираются полностью; ничего не домысливается |
| подстройка под случай | ЗАПРЕЩЕНА |

заголовок нельзя.
