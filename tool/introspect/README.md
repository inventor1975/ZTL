# introspect + zchoose

Разложение на **атомы** — элементарные claim'ы и допущения, на которых держится
код (`introspect`, тетрадь) или рассуждение (`zchoose`, тело яруса 3) — с меткой
статуса у каждого. **Судья — не ключ, а форк или я сам** (см. ниже).

```
# код:
./introspect.py prepare  <файл-или-папка> [--out DIR]
./introspect.py assemble <папка-вердиктов> [--out ledger.md]

# проза/рассуждение:
./zchoose.py prepare  <текст-файл> [--out DIR] [--lines 50]
./zchoose.py assemble <папка-вердиктов> [--out ledger.md]
```

Метки (ось ЦЕННОСТИ — общая для обоих, из `zchoose.VALUE_MARKS`; плюс проверочные):

| метка | значение |
|---|---|
| **T**  | ДОБРОЕ / проверено — истинно, стоит само, не во вред |
| **T?** | T-УЯЗВИМОЕ — доброе КАК СКАЗАНО, но оборачивается во вред при иной рамке/входе |
| **S**  | СОБЛАЗН (Seduction) — истинное зерно УЖЕ обёрнуто во вред (утечка, рост без предела; в прозе — правда для оправдания холода/расчёта) |
| **F**  | утверждается, но ЛОЖНО |
| **Z**  | взято в КРЕДИТ — допущение, которое не проверяется |
| **E**  | судить не на чем |

Это разметка СТАТУСА, не поиск багов: показывает, ГДЕ берётся кредит и где соблазн,
решение — за человеком. Метка **S** — ключевая: у T/F/Z/E нет клетки для «истинно,
но вредно». **T?** — граница: доброе, что легко оборачивается рамкой.

## Без ключа — судья форк или я

Инструмент API НЕ зовёт (не жжёт ничей ключ). `prepare` режет вход по естественным
швам и пишет по task'у на кусок (рубрика + текст); судит их:

- **ФОРК** — субагент на каждый task, параллельно (как линза, только вместо «найди
  баги» задача «размерь атомы»). Для большого (книга, проект).
- **САМ** — я размечаю task'и в своём контексте, без субагента. Для малого (абзац,
  один файл): форк ради абзаца — лишнее.

Оба идут по бюджету сессии, не по API-ключу. `assemble` сшивает вердикты (по
`verdict-NN.md`) в единый credit-ledger со сводкой меток.

## Тетрадь на теле

Метки оси ценности (T/T?/S) у обоих — ОДНО определение (`zchoose.VALUE_MARKS`):
тело — источник, тетрадь — рука. Улучшил тело — улучшил тетрадь.

## Что промерено

- Дополняет линзы, не заменяет: перечисляет кредит (провенанс), где линза судит
  «баг/не баг» и может молча похоронить непроверенный инвариант.
- Чанкинг прозы: нужен для длинного (целое не по зубам судье за раз), режется по
  главам/абзацам, НЕ поперёк довода — на ценностной оси рамка И ЕСТЬ суждение.
- Известный предел: метит УПОТРЕБЛЕНИЕ, но путает с УПОМИНАНИЕМ — процитированный и
  тут же опровергнутый соблазн может пометиться S. Родословная и промеры — в памяти.
