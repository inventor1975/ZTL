# Прогноз ДО доказательства — структурный признак наследственности (E57)

Заморожено 2026-09-06 до промера и до первой строки Lean. Куратор отдал выбор
мне («по ходу важности»); выбрано третье — §27: «остаётся открытым
структурный, неперечислительный критерий наследственной гарантии».

## Замысел (3 строки)
1. Сторож классичности: `G(x⃗) := ∧ᵢ (xᵢ ∨ ¬xᵢ)` — исключённое третье как
   измеритель «всё проверено»: при любом xᵢ = Z даёт F (Z ∨ ¬Z = Z ∨ F = F),
   при любом классическом наборе — T.
2. Формула-свидетель `Φ_ψ := G(x⃗) → ψ(x⃗)` для классической ψ над теми же
   атомами: при всякой разметке с хотя бы одной меткой вердикт T (F → _ = T);
   при полном уточнении c — ψ(c) (классика на Z-свободном, `evalF_agrees`).
3. Теорема: `Hereditary Φ_ψ allZ ↔ ∀ c классическое, ψ(c) = T` — то есть
   наследственность T при всём-Z есть ТАВТОЛОГИЧНОСТЬ ψ. Следствие прозой:
   всякий неперечислительный (полиномиальный) признак наследственности решал
   бы TAUT; признака нет, если P ≠ coNP. Достаточные признаки есть
   (`NoGift.no_gift`: без метки под отрицанием) — точного нет.

## Прогноз
- Промер (zverify `hereditary_bit` против классической тавтологичности на
  пуле ψ над 2–3 атомами): расхождений 0.
- Lean: на пустом списке, поверх `ZTime` (своё V без tactic-инстансов —
  все трёхзначные факты явным `cases`, как в E33).
- Побочно, если дойду: ШИРИНА — «ширина 1» решается за m·2 вычислений
  (полиномиально; судья это уже делает как `joint`), а «ширина ≥ k» —
  NP-трудна тем же сторожем; не обещаю в этот заход.

## Чего НЕ жду
Что найдётся точный синтаксический признак: теорема выше говорит, что он
был бы решателем TAUT.

## ШИРИНА (E58) — прогноз ДО промера, дописано 2026-09-06 16:45

Ширина в приборе (`inventory/width/bench.py`): наименьшее число меток, чьё
СОВМЕСТНОЕ заполнение меняет жадный вердикт `ev(φ, m)`; `None`, если не меняет
никакое подмножество — то есть `None` ⟺ наследственность.

Прогноз на свидетеле `Φ_ψ = G_{n+1} → ψ` при всём-Z:
- любое подмножество, оставляющее хоть один охраняемый атом помеченным, вердикт
  не двигает (сторож F ⇒ T) — значит ширина ≥ n+1 всегда;
- ширина = n+1 ⟺ ∃ классическое c с ψ(c) = F; иначе `None`.
- Промер на пуле глубины ≤ 2 над p,q (n+1 = 2): ширина ∈ {2, None}, и
  «2 ⟺ ψ не тавтология» — расхождений 0.
- Lean (`ZWidthHard.lean`, пустой список): `no_move_below` (меньше n+1 не
  сдвинуть) и `width_iff_refutable` (сдвиг при n+1 ⟺ ¬ψ выполнима).
- Следствие прозой: «ширина ≤ k» NP-полна (гипотеза S и уточнение — сертификат;
  трудность — SAT через свидетеля). Поле `joint` судьи, отвечающее на «ширина = 1»
  за 2m вычислений, — правильный срез: единица дёшева, точное число нет.
