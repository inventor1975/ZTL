# introspect

Разложение кода на **атомы** — элементарные claim'ы и допущения, на которых код
держится, — с меткой статуса проверки у каждого. Судья Опус, не эвристика.

```
./introspect.py <файл-или-папка> [--out ledger.md] [--model claude-opus-4-8] [--jobs 6]
```

Пять меток:

| метка | значение |
|---|---|
| **T** | проверено ВЕРНО самим кодом (гарантирует на всех входах) |
| **F** | утверждается, но ЛОЖНО |
| **Z** | взято в КРЕДИТ — допущение, которое код НЕ проверяет |
| **E** | судить не на чем |
| **S** | СОБЛАЗН (Seduction) — истинно, но во ВРЕД: утечка, рост без предела, пропавший инвариант без падения |

Инструмент выдаёт только действенное (Z/F/S) плюс счётчики T/E, файл за файлом,
в единый credit-ledger. Это разметка СТАТУСА, не поиск багов: он показывает, ГДЕ
проект берёт в кредит и где соблазн, а решение — за человеком.

Метка **S** — ключевая находка: у T/F/Z/E нет клетки для «истинно, но вредно»
(утечка памяти — правдивое свойство, не ложь и не непроверенное допущение).

## Ключ

Токены биллятся на Anthropic-ключ. Порядок поиска: `$ANTHROPIC_API_KEY` → `--key
<файл>` → `$INTROSPECT_KEYFILE` → `./.anthropic_key` рядом со скриптом.

## Что промерено

- Тетрадь **дополняет** линзы, не заменяет: перечисляет кредит (провенанс), тогда
  как линза судит «баг/не баг» и может молча похоронить непроверенный инвариант.
- На известном коде с посаженными багами инструмент берёт crash-кредиты (KeyError/
  ValueError) и — благодаря метке S — утечки/рост без предела, которые чистая
  разметка T/F/Z/E пропускает.
- Цена держится ~на файл, не на строку; компактный вывод дешевле полной таблицы.

Требует пакет `anthropic`. Родословная и промеры — в памяти проекта.
