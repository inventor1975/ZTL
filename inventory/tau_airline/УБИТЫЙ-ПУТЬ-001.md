# Убитый путь замера 001 — «78% settles» в багажном правиле

Сохранено по требованию внешнего рецензента: путь замера, оказавшийся негодным, не
стирается. История утверждений должна быть осматриваема.

## Что было объявлено первым прогоном

    БАГАЖНЫХ ДЕЙСТВИЙ С КЛАССОМ И ЧИСЛОМ МЕСТ: 9
      проверка уровня НИЧЕГО НЕ РЕШАЕТ (settles): 7 = 78%
      проверка уровня РЕШАЕТ                    : 2 = 22%

## Фальсификатор

Все семь «settles» — случаи `запрошено 0 мест`.

## Поправка, и почему НЕ пятая корзина

Сперва я отделил их как «вырожденные» — то есть завёл ПЯТУЮ корзину, чтобы
сохранить первую классификацию. внешний рецензент это отбил, и верно: решать надо по
структуре решения, а не по удобству.

    доплата = 50 * max(0, bags - allowance(уровень, класс))

При `bags = 0` внешний `max` обращается в ноль ПРИ ЛЮБОМ `allowance`. Значит
НАБЛЮДЁННОЕ значение — запрошено ноль — уже определяет полное последствие, и
уровень мёртв ровно по той причине, по какой мёртв правый операнд у `&&`.
Это определение СОКРАЩЕНИЯ в замороженном разбиении. Разряд существующий,
новый заводить не требовалось.

## Что осталось после поправки

    СОКРАЩЕНИЕ (запрошено 0 мест)  : 7 — заявлять нечего
    НЕВЫРОЖДЕННЫХ (мест >= 1)      : 2
      settles : 0
      решает  : 2

## Три числа после вычитания обычного вычислителя

    наших settles (невырожденных)    : 0
    из них берёт обычный вычислитель : 0
    ОСТАТОК, уникально наш           : 0

**И этот ноль не читается как «мы не хуже».** Находок нет вовсе — значит
вычитать не из чего, и об остатке на этих данных нельзя утверждать ни в ту,
ни в другую сторону. Прибор говорит это сам, чтобы цитата не оторвалась от
оговорки.

Для сведения: сокращений, которые обычный вычислитель тоже берёт, — **7 из 7**.
На этом правиле он справляется со всем, что вообще встретилось.

## Точные формулировки

- **ПРОМЕРЕНО:** обе невырожденные возможности проверки уровня в корпусе из
  50 задач чувствительны к исходу.
- **ПРОМЕРЕНО:** ни одного настоящего `settles` по уровню в этих двух
  возможностях не наблюдалось.
- **НЕ УСТАНОВЛЕНО:** распространённость настоящего `settles` в числовых и
  пороговых правилах airline. Два случая не подтверждают и не опровергают
  прогноз о сосредоточении — они просто не о том.
