## Замысел (3 строки)
1. Свидетель `R_ψ := (a ∨ (ψ ∧ ¬ψ)) ∧ ψ` для ψ без атома `a` и без констант.
   `ψ ∧ ¬ψ` — «ложь, сохраняющая Z»: Z ровно там, где ψ = Z, иначе F. На всём-Z
   `R_ψ` ожидает и квитанция называет `a` (`labF allZ R_ψ a = true`).
2. Теорема: `pivotal allZ R_ψ a ↔ ∃ классическое c, evalK c ψ = T` — T-сторона
   есть ψ(w), F-сторона есть (ψ∧¬ψ)(w); различны ⟺ ψ(w) = T; частичное w с
   ψ = T доводится до классического монотонностью `evalK`.
3. Следствие ПРОЗОЙ, одним шагом, с грейдом урока 06.09: решить, назван ли атом
   впустую, значит решить выполнимость ψ — точная квитанция **NP-трудна**.
   Принадлежность NP не заявляется. `labF` — дешёвый список кандидатов —
   вынужденный срез, как `joint` в E58. Тройка замыкается: наследственность
   coNP-трудна (E57), ширина NP-трудна (E58), точная квитанция NP-трудна (E59).
